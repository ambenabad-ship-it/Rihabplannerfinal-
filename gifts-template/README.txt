GIFT IMAGES — naming convention
================================

Folder structure:
  bundle_01/   ← palier 1
  bundle_02/   ← palier 2
  ...
  bundle_14/  ← palier 14

Filenames inside each folder MUST start with the tier number:
  C1_*.jpg / .png / .webp   → photo for Prize 1
  C2_*...                   → photo for Prize 2
  C3_*...                   → photo for Prize 3

For multi-photo prizes (e.g. "Triporteur + TV"), add a suffix letter:
  C3a_Triporteur.jpg
  C3b_Samsung_50_4K.jpg
  → both will appear in the Prize 3 carousel for that palier.

Anything after the tier prefix is free text. Rename, reorder, replace — the
app only looks at the C1 / C2 / C3 prefix.

Once filled, upload the WHOLE folder via Data Sources → Gift Images.
